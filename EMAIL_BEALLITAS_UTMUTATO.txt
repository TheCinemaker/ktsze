2. RESEND BEÁLLÍTÁSOK (Küldő motor & SMTP)
--------------------------------------------------------------------------------
Weboldal: https://resend.com

  A) Ha új API kulcs kell a belépéshez (mivel nem olvasható ki újra):
     1. Menj a "API Keys" menüre (resend.com/api-keys).
     2. Kattints a "Create API Key" gombra.
     3. Név: pl. "Gmail SMTP Szilveszter"
     4. Permission: "Full access" vagy "Sending access"
     5. Másold ki az új kulcsot (így kezdődik: re_...).

  B) SMTP Szerver Adatok (ezt kell beírni a levelezőkbe):
     - SMTP Szerver:    smtp.resend.com
     - Port:           465 (SSL) vagy 587 (TLS)
     - Felhasználónév: resend  (szó szerint ez a szó, kisbetűvel!)
     - Jelszó:         A generált Resend API kulcs (re_...)

3. GMAIL BEÁLLÍTÁS (Hogyan tudsz küldeni a saját @ktsze.hu címedről)
--------------------------------------------------------------------------------
Ezt mindenki a saját Gmail fiókjában tudja megcsinálni (pl. admin.ktsze, avar.szilveszter):

  1. Lépj be a Gmailbe számítógépen.
  2. Jobb felső sarok: Fogaskerék -> "Az összes beállítás megtekintése".
  3. Menj a "Fiókok és importálás" fülre.
  4. A "Levélküldés más címről" résznél kattints:
     -> "További saját e-mail cím hozzáadása"
  5. 1. Ablak:
     - Név: tetszőleges (pl. "Avar Szilveszter | KTSZE" vagy "KTSZE Info")
     - E-mail cím: a saját @ktsze.hu címed (pl. info@ktsze.hu vagy s.avar@ktsze.hu)
     - "Álnévként kezelendő": VEDD KI A PIPÁT!
     - Kattints a "Következő lépés"-re.
  6. 2. Ablak:
     - SMTP-szerver: smtp.resend.com
     - Port: 465
     - Felhasználónév: resend
     - Jelszó: a Resend API kulcsod (re_...)
     - Biztonságos kapcsolat SSL használatával (bejelölve)
     - Kattints: "Fiók hozzáadása".
  7. Megerősítés:
     - A Gmail küld egy számkódot a @ktsze.hu-s címedre.
     - Mivel a Cloudflare már továbbítja a leveleket, ez a kód másodperceken 
       belül megérkezik a rendes Gmail beérkező leveleid közé.
     - Írd be a kódot a felugró ablakba -> Ellenőrzés. KÉSZ!

  8. EXTRA KÉNYELMI BEÁLLÍTÁS (hogy automatikusan a jó címről válaszolj):
     Ugyanitt a Gmail "Fiókok és importálás" fülön a 
     "Levélre való válaszoláskor" résznél válaszd ezt:
     -> [x] "Válasz arról a címről, amelyre az üzenet érkezett"
